# NRSuite Example Downloads

These files are small examples for authorized testing and documentation.
They are not production payloads.

- `portal-example.html` — starter captive-portal page using the `#SSID#` token.
- `duckyscript-notepad-example.txt` — harmless DuckyScript notepad demo.
- `ir-example.ir` — minimal Flipper `.ir` parsed-signal example.
- `config-example.json` — illustrative configuration values.
- `sample-wordlist.txt` — tiny placeholder wordlist for workflow testing.

Only use NRSuite and these examples on devices and networks you own or have
explicit written permission to test.
